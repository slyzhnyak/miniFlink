Module Mf_event

Событие потока: данные, watermark или отмена.

Все три конструктора текут по одному потоку и обрабатываются операторами через pattern matching — единообразно и с проверкой полноты компилятором.

type 'a t =
  1. | Data of 'a * Time.t
    (*

    значение + его event-time

    *)
  2. | Watermark of Time.t
    (*

    граница: события раньше уже пришли

    *)
  3. | Retract of 'a * Time.t
    (*

    отмена ранее выданного результата

    *)

Событие со значением 'a.

val data : 'a -> Time.t -> 'b t
val retract : 'a -> Time.t -> 'b t
val wm : Time.t -> 'a t
val value : 'a t -> 'b option
val ts : 'a t -> Time.t
val is_data : 'a t -> bool
val map_value : ('a -> 'b) -> 'c t -> 'd t
val with_watermarks_ext : latency:int -> ?interval:int -> 'a t Stream.t -> 'a0 t Stream.t

with_watermarks_ext ~latency ?interval src вставляет watermark-маркеры в поток. Watermark = max_seen - latency: все события с меньшим timestamp считаются прибывшими.

  • ~latency — допуск на опоздание (out-of-orderness).
  • ~interval — минимальный сдвиг watermark перед новой эмиссией (по event-time). При interval=0 watermark эмитится на каждый новый максимум; больший interval уменьшает их число.

На конце потока эмитится финальный watermark = max_seen, чтобы закрыть все хвостовые окна.

val with_watermarks : latency:int -> 'a t Stream.t -> 'a t Stream.t

with_watermarks ~latency src — то же что with_watermarks_ext с ~interval:0 (watermark на каждый новый максимум). Обратно совместимая форма.
